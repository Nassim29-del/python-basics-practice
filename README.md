# python-basics-practice

A set of small Python exercises for practicing core fundamentals — loops,
conditionals, functions, strings, and basic I/O.

Each folder holds one self-contained script. Run any of them with:

```bash
python3 01-temperature-converter/temperature_converter.py
```

## Exercises

| #  | Exercise | Practises |
|----|----------|-----------|
| 01 | Temperature converter | functions, input handling |
| 02 | Simple calculator | operators, divide-by-zero handling |
| 03 | FizzBuzz | loops, modulo |
| 04 | Dice roller | random, tallies |
| 05 | Rock, paper, scissors | conditionals, loops |
| 06 | Countdown timer | time.sleep, formatting |
| 07 | BMI calculator | arithmetic, categories |
| 08 | Multiplication table | nested loops, alignment |
| 09 | Palindrome checker | string reversal |
| 10 | Vowel counter | membership tests |
| 11 | Leap year checker | compound conditionals |
| 12 | Simple interest | formula, formatting |
| 13 | Number to words (1–100) | dictionaries, logic |
| 14 | Guess the number | loops, comparison |
| 15 | Grade calculator | averaging, letter grades |

Labelled honestly as practice — not fifteen separate projects.
